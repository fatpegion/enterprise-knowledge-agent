# 复盘

最难的问题是让一条看似可信的制度答案保留来源，又能在另一份制度出现后及时改变结论。检索把候选与正文分开，模型先读原文再决定是否补查。代码只允许引用已读片段。资料替换实验用同一问题比较两套资料，检查答案和动作是否随证据变化。

实现验证中，单元测试覆盖执行器与引用约束，Mock 用于复现流程，真实模型运行用于评估观察后的动作选择。一次复测只读到 D01 就提前作答，触发了增加候选覆盖校验的改动。按分数筛选待核对文档又误把分辨率和水印放在一起，所以最终用显式制度事项标记缩小校验范围。校验将同一事项未读的文档返给模型，由模型选择下一步。用合成同义词改善了已知改写的初检，面对未配置词汇仍依赖模型改写查询。

下一轮优先加入多条款、跨部门适用规则和更大候选集的测试，再比较词表检索与更强检索器的候选召回。当前交付包含本地 CLI、合成资料与验证材料。线上部署、持久化对话和真实企业资料评估尚未实施。

Codex 的实施与验证约用 35 分钟，含下载模型和多轮验收。候选人独立开发和复跑用时待本人记录。
